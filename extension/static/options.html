Space Writer

打开已登录的 kintone Space 话题页，选择小窗中的文章版本，写入后检查并发布。

文章与小窗设置

导入会合并归档状态和小窗设置，同名条目使用导入的值。文章文件、图片和 Bridge 队列仍保存在本地文章库中。

从 Tampermonkey 迁移

  1. 在原浏览器配置中安装 ZIP 内 migration 文件夹的 export-settings.user.js。它会替换旧 Space Writer 脚本，并保留原脚本的设置。
  2. 刷新 kintone 话题页，点击“导出旧版设置”，保存 JSON。
  3. 停用 Tampermonkey 中的 Space Writer 导出脚本，在本页导入 JSON，再刷新 kintone 页面。

如需回退，可从 ZIP 中的旧版脚本恢复。旧版只用于回退，正常使用扩展时请保持停用。

安装与更新

保持解压目录固定。更新时用新版文件替换该目录，然后在浏览器扩展管理页点击“重新加载”，再刷新 kintone 页面。保留扩展安装即可保留设置。
