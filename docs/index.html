kintone Space Writer 浏览器脚本

在已安装 Tampermonkey 的浏览器中，点击下方按钮安装脚本。首次安装或从本地文件迁移时，确认 Tampermonkey 的安装或更新提示。

安装或更新脚本

安装后，打开 kintone Space 话题页。脚本会连接本机运行的 Space Writer Bridge，读取已准备好的文章版本。脚本更新由 Tampermonkey 按设置检查；文章仍需在页面中由你确认并发布。

如果浏览器显示脚本源码，请复制此直链到 Tampermonkey 的“实用工具 → 从 URL 安装”：
https://forestsheep911.github.io/kintone-space-writer/kintone-space-writer.user.js
